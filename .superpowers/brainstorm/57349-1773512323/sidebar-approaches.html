紧凑文件树

类似 VS Code 侧栏。每行极小，文件夹可折叠，10+ 个文件也不怕。上传时弹出选文件夹的对话框。

优点

  • 密度最高，最多文件
  • 折叠操作直觉

缺点

  • 风格与现有 UI 差异大
  • 拖拽体验弱

文件夹 Tab + 文件列表

顶部是文件夹 Tab，点击切换。当前文件夹的文件以紧凑列表展示。上传时自动归入当前 Tab 的文件夹。

优点

  • 文件夹切换一键
  • 和现有圆角风格融合好

缺点

  • 看不到所有文件夹同时
  • 文件夹多了 Tab 会挤

现有结构 + 精简卡片

保留折叠文件夹的结构，把每个文件的大卡片换成 1 行紧凑行。操作菜单（⋯）展开删除/移动。风格改动最小。

优点

  • 改动最少，风险低
  • 拖拽逻辑可以保留

缺点

  • 密度提升有限
  • 没有彻底解决文件夹多的问题

💡 上传时弹出"选择文件夹"对话框这个功能，3 个方案都可以做。这里主要选侧栏布局方向。
