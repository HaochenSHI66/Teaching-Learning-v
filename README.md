## 🤔 解决什么问题？

> 上课看 PPT 看不懂，课后复习没讲解，翻教材效率低。

**幻灯片研习台**让你上传课件 PDF，AI 自动逐页生成结构化讲解——每个知识点拆成卡片，术语中英对照，重点高亮，公式渲染，就像一个随时在线的课程助教。

---

## ✨ 功能一览

### 🤖 AI 智能讲解
- **双模型管线** — 视觉模型读图 + 文本模型生成讲解，不遗漏图表内容
- **结构化卡片** — 每页 4-8 个知识点，不是大段文字，而是清晰的分点讲解
- **术语对照** — 专业术语自动标注 **中文 (English)** 格式
- **重点标注** — 高亮核心结论，Callout 提示框区分「重点 / 提示 / 注意 / 说明」
- **公式渲染** — 行内公式 $...$ 和独立公式 $$...$$ 完美呈现
- **代码讲解** — 代码页自动引用代码并逐段解释

### 📚 学习工具
- **追问对话** — 看不懂？直接追问，AI 基于当前页上下文回答
- **框选讲解** — 框选 PPT 上任意区域，AI 重点解释选中部分
- **概念图谱** — 自动提取学科概念，可视化概念间的关系网络
- **闪卡复习** — 一键生成复习卡片，帮你巩固核心知识
- **笔记导出** — 把 AI 讲解导出为 HTML/PDF 格式的学习笔记

### 🗂️ 文档管理
- **文件夹分类** — 按课程、学期整理你的课件
- **拖拽排序** — 自由调整文档和文件夹顺序
- **书签标记** — 标记重点页、难点页、待复习页
- **全量解析** — 一键为整个文档生成所有页面的讲解

### 🎨 体验细节
- **分屏布局** — 左侧 PPT 原页，右侧 AI 讲解，对照学习
- **暗色主题** — 深夜复习不伤眼
- **页面预加载** — 打开文档后自动缓存所有页面，切页秒开
- **自动登录** — 勾选后下次打开直接进入

## 🚀 怎么用？

### 在线使用（推荐）

直接访问 **[learn.shc66.com](https://learn.shc66.com)**，注册账号即可使用，无需安装。

### 使用流程

1. **注册/登录** — 打开网站，注册一个账号
2. **上传课件** — 点击「上传 PDF/图片」，拖入你的 PPT 或 PDF 文件
3. **等待处理** — 系统自动渲染页面、提取文字
4. **生成讲解** — 点击「生成解析」或「为所有页面生成解析」
5. **学习** — 逐页浏览，看 AI 讲解，不懂就追问
