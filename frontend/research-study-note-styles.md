## Part 1: Top 8 Distinct Visual Styles for Study Notes

### Style 1: Cornell Method (康奈尔笔记法)

| Attribute | Detail |
|-----------|--------|
| **Layout** | Page divided into 3 sections: narrow left column (cues/keywords), wide right column (detailed notes), bottom strip (summary) |
| **Colors** | Typically 2-3 colors. One for headings, one for body, one for highlights. Clean and academic |
| **Typography** | Clear hierarchy: bold titles, regular body, smaller cue text |
| **Icons/Borders** | Section dividers (horizontal + vertical lines). Minimal icons. Emphasis via underline or highlight |
| **Best For** | STEM courses, history, law, lecture-heavy classes requiring structured recall |
| **Popularity** | Very high. The most-recommended method across university resources, Notion templates, and Goodnotes. A classic that remains dominant |

---

### Style 2: Mind Map / Mapping (思维导图)

| Attribute | Detail |
|-----------|--------|
| **Layout** | Central topic in the middle, branches radiating outward. Sub-branches for details. Non-linear, organic |
| **Colors** | Multi-color is essential. Each main branch uses a different color. 4-8 colors typical |
| **Typography** | Central topic largest/boldest. Branch labels medium. Leaf nodes smallest. Mixed hand-drawn + print |
| **Icons/Borders** | Heavy use of icons, small drawings, curved connectors, arrows. Bubbles/clouds around concepts |
| **Best For** | Brainstorming, creative subjects, revision, understanding relationships between concepts |
| **Popularity** | Very high. Trending upward with digital tools (XMind, MindNode, Notion AI). Popular on Pinterest with 'aesthetic mind map' searches |

---

### Style 3: Aesthetic Pastel / Soft Color Notes (粉彩美学笔记)

| Attribute | Detail |
|-----------|--------|
| **Layout** | Structured but decorative. Headers with banners/ribbons. Indented bullet points. White space intentional |
| **Colors** | Pastel palette: light pink, lavender, mint green, soft blue, peach. Typically 3-5 pastel shades |
| **Typography** | Calligraphy-style headers, clean print body text. Decorative lettering for titles |
| **Icons/Borders** | Digital stickers, washi tape borders, small doodles (flowers, stars, hearts). Highlighted text boxes. Decorative dividers |
| **Best For** | General study notes, revision summaries, personal knowledge bases. Extremely popular on iPad/Goodnotes |
| **Popularity** | Extremely high on Pinterest and social media. The dominant "studygram" aesthetic. Peak trend 2023-2026 |

---

### Style 4: Sketchnotes / Visual Notes (视觉笔记 / 涂鸦笔记)

| Attribute | Detail |
|-----------|--------|
| **Layout** | Non-linear. Modular, flowing, or "popcorn" layouts. Content placed spatially, not sequentially |
| **Colors** | Typically limited palette: black + 1-2 accent colors. Or full color for emphasis |
| **Typography** | Hand-drawn fancy typography. Mixed sizes. Titles in block letters, body in handwriting. Banners for headings |
| **Icons/Borders** | Core element. Icons, simple sketches, containers (boxes, circles, speech bubbles), arrows, connectors, banners |
| **Best For** | Conference talks, biology/medicine, design thinking, any content benefiting from visual memory hooks |
| **Popularity** | High and growing. Strong community (Mike Rohde's movement). Popular in design and creative education circles |

---

### Style 5: Minimalist / Clean Digital (极简主义笔记)

| Attribute | Detail |
|-----------|--------|
| **Layout** | Generous white space. Clear heading hierarchy. Grid-aligned. Maximum 2-3 levels of nesting |
| **Colors** | Monochrome or near-monochrome: black, dark grey, white. One accent color at most |
| **Typography** | Sans-serif fonts. Consistent sizing. Bold for headings, regular for body. No decorative elements |
| **Icons/Borders** | Minimal to none. Simple horizontal rules as dividers. Checkboxes for tasks. Clean lines only |
| **Best For** | Technical documentation, programming notes, daily task management, Notion/Obsidian power users |
| **Popularity** | Very high among productivity communities. Default Notion aesthetic. Trending with "digital minimalism" movement |

---

### Style 6: Boxing / Modular Method (方框笔记法)

| Attribute | Detail |
|-----------|--------|
| **Layout** | Each topic/subtopic contained in its own labeled box or card. Grid-like arrangement on page |
| **Colors** | Color-coded boxes by category or importance. Typically 3-5 distinct box colors |
| **Typography** | Bold box titles, regular body within boxes. Consistent across all modules |
| **Icons/Borders** | Strong borders are the defining feature. Rounded or sharp-cornered boxes. Connecting lines between related boxes |
| **Best For** | Revision and summary pages. Comparing topics. Science subjects with distinct concept groups |
| **Popularity** | Medium-high. Growing on Goodnotes and iPad communities. Popular for exam revision |

---

### Style 7: Dark Academia / Moody Aesthetic (暗色学院风笔记)

| Attribute | Detail |
|-----------|--------|
| **Layout** | Traditional/classic layout. Structured columns. Resembles aged paper or journal entries |
| **Colors** | Dark backgrounds: deep brown, navy, forest green, charcoal. Gold/cream/amber accents. Warm tones |
| **Typography** | Serif fonts, cursive/calligraphy headers. Vintage book aesthetic. Sometimes Gothic lettering |
| **Icons/Borders** | Ornamental borders, book-style decorations, vintage stamps, botanical drawings, quill/ink motifs |
| **Best For** | Literature, philosophy, history, humanities. Personal journaling and reading notes |
| **Popularity** | High on Pinterest and TikTok. One of the top Notion aesthetic themes. Strong Gen Z following. Poetcore trend (175% increase on Pinterest for 2026) |

---

### Style 8: Outline / Bullet Method (大纲笔记法)

| Attribute | Detail |
|-----------|--------|
| **Layout** | Strictly hierarchical. Main topics as top-level bullets, subtopics indented, details further indented. Linear, top-to-bottom |
| **Colors** | Typically 1-2 colors. Some use color-coded indent levels. Clean and functional |
| **Typography** | Consistent font. Size/weight varies by hierarchy level. Markdown-style (H1, H2, H3) in digital |
| **Icons/Borders** | Minimal. Bullet points (dots, dashes, numbers). Occasional checkboxes. No decorative elements |
| **Best For** | Fast lectures with clear structure. Technical courses. Meeting notes. Any content with obvious hierarchy |
| **Popularity** | Very high. The default method for most note-taking apps (Obsidian, Notion, Logseq). Universal baseline |

## Part 3: Export Format Comparison

### Format Comparison Matrix

| Criteria | PDF | HTML | Markdown | DOCX |
|----------|-----|------|----------|------|
| **Styling Preservation** | Excellent. WYSIWYG. Pixel-perfect | Excellent. Full CSS control | Poor. Plain text with limited formatting | Good. Headings, tables, basic styling |
| **Rich Visual Support** | Full: images, colors, fonts, borders, custom layouts | Full: anything CSS can do | Limited: images via links, no colors/borders natively | Moderate: images, basic tables, limited layout |
| **Print Quality** | Best. Designed for print | Good (via browser print) | Poor without conversion | Good |
| **File Size** | Medium-large | Small-medium | Smallest | Medium |
| **Editability** | Poor. Read-only by design | Good (with HTML knowledge) | Best. Plain text, any editor | Good. Word processors |
| **Obsidian Import** | View only (PDF++ plugin) | Not native | Native format. Perfect | Via plugin conversion |
| **Notion Import** | Upload as embed | Not native | Native import. Good | Upload as file |
| **Cross-Platform** | Universal | Universal (browser) | Universal (text editor) | Needs Word/compatible app |
| **Future-Proof** | Very good | Very good | Best. Plain text forever | Good but proprietary |
| **Interactivity** | None | Full (links, toggles, animations) | Limited (links only) | Limited |

### Recommendations by Use Case

**For beautiful, shareable notes (printing/presentation)**:
- Winner: **PDF**
- Preserves exact visual design. Universal viewing. Best print quality.
- Export from: Obsidian (Better Export PDF plugin), Notion (native), Goodnotes (native)

**For maximum styling + interactivity (web sharing)**:
- Winner: **HTML**
- Full CSS styling, responsive design, embedded media, interactive elements
- Can replicate any visual note style with proper CSS
- Export from: Obsidian (Publish or HTML export plugin), Notion (not native but API-based)

**For knowledge management + portability (Obsidian/Notion ecosystem)**:
- Winner: **Markdown**
- Native format for Obsidian. Easily imported to Notion.
- Future-proof plain text. Version-controllable with Git.
- Limitation: Cannot natively represent colors, borders, complex layouts
- Workaround: Extended Markdown (Obsidian callouts, Notion blocks) or embedded HTML

**For collaboration + academic submission**:
- Winner: **DOCX**
- Editable by collaborators. Required by many academic institutions.
- Pandoc converts Markdown to DOCX with templates

### Best Strategy for Students
Use **Markdown** as the source format (write in Obsidian/Notion), then export to:
- **PDF** for printing and sharing beautiful formatted versions
- **HTML** for web publishing or interactive study materials
- **DOCX** for academic submission when required

Tools: Pandoc (universal converter), Obsidian Better Export PDF, Notion native export, iA Writer (academic templates)
